# 程序员之家招新展示站

现场演示时，双击 `打开招新网站.cmd` 即可用默认浏览器打开。网站使用纯静态文件和本地素材，无需安装依赖，也不依赖网络。

## 演示快捷键

- 按 `F` 或点击右上角“全屏演示”进入浏览器全屏
- 按 `Esc` 退出全屏
- 顶部导航可快速切换展示章节
- 荣誉区视频由右下角按钮播放，保留完整音效，并支持暂停或重播
- 荣誉区可使用左右按钮、鼠标拖动、滚轮或方向键浏览全部奖状

## 文件说明

- `index.html`：页面内容
- `styles.css`：视觉样式与响应式布局
- `script.js`：动效、全屏、证书预览
- `assets/`：已针对网页加载优化的图片与荣誉展示视频
